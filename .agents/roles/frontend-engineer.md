3. **Responsive:** Code phải hiển thị đẹp trên cả Mobile, Tablet và Desktop.
4. **Luật ngầm:** Luôn luôn đọc và tuân thủ `.agents/rules/web-conventions.md`. Cấm sửa code Backend (`apps/core`).
